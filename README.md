# 🤖 JokerBot

A fun Telegram bot that tells jokes, shares trivia, and brings laughter to your chats!

## ✨ Features

- 😂 **Jokes**: 100+ jokes across 5 categories (General, Dad, Pun, Programming, Animals)
- 📊 **Trivia**: Test your knowledge with random trivia questions
- 💡 **Fun Facts**: Learn something new every day
- 🎲 **Roll Dice**: Roll a dice with custom sides
- 🪙 **Flip Coin**: Heads or tails?
- 📋 **Interactive Menu**: User-friendly inline keyboard navigation

## 🚀 Commands

| Command | Description |
|---------|-------------|
| `/start` | Welcome message with interactive menu |
| `/menu` | Show all available commands |
| `/joke` | Get a random joke |
| `/joke [category]` | Get joke by category (dad, pun, programming, animals, general) |
| `/roll [sides]` | Roll a dice (default 6 sides) |
| `/flip` | Flip a coin |
| `/trivia` | Random trivia question |
| `/fact` | Random fun fact |
| `/about` | About this bot |

## 🛠️ Tech Stack

- Python 3.9+
- python-telegram-bot library
- Deployed on Railway
- Hosted on GitHub
